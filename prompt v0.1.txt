## TECH STACK

### Backend
- **Framework:** FastAPI (Python 3.13) with async/await
- **ORM:** SQLAlchemy 2.0 with async sessions
- **Database:** SQLite (development) → PostgreSQL (production planned)
- **Migrations:** Alembic (configured but currently using auto-create on startup)
- **Auth:** JWT with python-jose, password hashing with SHA256 (temporary, bcrypt had issues on Windows)
- **Server:** Uvicorn with hot reload

### Frontend
- **Framework:** Vue 3 with Composition API (`<script setup>`)
- **Build Tool:** Vite
- **State Management:** Pinia
- **Routing:** Vue Router 4
- **CSS:** Tailwind CSS 3 with custom theme system
- **Icons:** Lucide Vue Next
- **HTTP Client:** Axios with interceptors for JWT
- **Fonts:** Vazirmatn (modern), BNazanin (classic Persian)

## DATABASE MODELS

### User
- id, email (unique), hashed_password, is_active
- Timestamps: created_at, updated_at

### Task
- id, title, description, due_date, priority (0-2), is_completed
- owner_id → FK users.id
- Timestamps: created_at, updated_at

### Goal
- id, title, description, start_date, target_date
- current_status, current_obstacle, next_step
- priority (0-2), success_criteria, is_completed, progress_percent
- owner_id → FK users.id
- Timestamps: created_at, updated_at

### GoalLog (Audit Trail)
- id, goal_id → FK goals.id (CASCADE), action (created/updated/deleted)
- field_name, old_value, new_value, description
- owner_id → FK users.id
- Timestamps: created_at, updated_at

### SubGoal
- id, goal_id → FK goals.id (CASCADE), title, description
- start_date, target_date, status (not_started/in_progress/completed)
- progress_percent, order_index
- owner_id → FK users.id
- Relationship: tasks → SubGoalTask (cascade delete)
- Timestamps: created_at, updated_at

### SubGoalTask
- id, sub_goal_id → FK sub_goals.id (CASCADE), title
- is_completed, priority, due_date
- owner_id → FK users.id
- Timestamps: created_at, updated_at

### KPI
- id, goal_id → FK goals.id (CASCADE), title, unit
- target_value (float), current_value (float)
- frequency (daily/weekly/monthly), last_updated
- owner_id → FK users.id
- Timestamps: created_at, updated_at

## API ENDPOINTS

### Auth
- POST /api/v1/auth/register - Register new user
- POST /api/v1/auth/login - Login, returns JWT

### Tasks
- GET /api/v1/tasks - List tasks (temp: uses fixed user_id=1)
- POST /api/v1/tasks - Create task
- PUT /api/v1/tasks/{id} - Update task
- DELETE /api/v1/tasks/{id} - Delete task

### Goals
- GET /api/v1/goals - List goals (temp: user_id=1)
- POST /api/v1/goals - Create goal (auto-logs creation)
- PUT /api/v1/goals/{id} - Update goal (auto-logs field changes)
- DELETE /api/v1/goals/{id} - Delete goal (auto-logs deletion)
- DELETE /api/v1/goals/all/reset - Delete all goals
- GET /api/v1/goals/logs - Get recent audit logs
- GET /api/v1/goals/{id}/logs - Get logs for specific goal

### Roadmap
- GET /api/v1/roadmap/goal/{goal_id}/subgoals - List subgoals with tasks
- POST /api/v1/roadmap/goal/{goal_id}/subgoals - Create subgoal
- PUT /api/v1/roadmap/subgoals/{id} - Update subgoal
- DELETE /api/v1/roadmap/subgoals/{id} - Delete subgoal
- POST /api/v1/roadmap/subgoals/{id}/tasks - Add task to subgoal
- PUT /api/v1/roadmap/tasks/{id} - Update subgoal task
- DELETE /api/v1/roadmap/tasks/{id} - Delete subgoal task
- GET /api/v1/roadmap/goal/{goal_id}/kpis - List KPIs
- POST /api/v1/roadmap/goal/{goal_id}/kpis - Create KPI
- PUT /api/v1/roadmap/kpis/{id} - Update KPI
- DELETE /api/v1/roadmap/kpis/{id} - Delete KPI

## IMPORTANT NOTES FOR CONTINUING DEVELOPMENT

### Authentication Hack:
Currently all API endpoints use `TEMP_USER_ID = 1` instead of proper JWT auth. The `get_current_user` dependency exists in `app/core/deps.py` but is not used. When implementing proper auth:
- Import and use `get_current_user` in all routers
- Replace `TEMP_USER_ID` with `current_user.id`
- Update frontend to send Bearer token (already configured in axios interceptor)
