Issue Description:

The frontend loads (e.g. on http://SERVER_IP:3000 or http://SERVER_IP), and the login UI renders cleanly.

❌ ارتباط با سرور برقرار نشد (پورت ۸۰۰۰ را بررسی کنید).
On a local laptop/browser, the API connection succeeds, but mobile connections from external networks fail to reach Port 8000.
Technical Analysis & Root Causes to Investigate:
Iranian Mobile Telecom Non-Standard Port Filtering:
Mobile ISPs in Iran (MCI / Irancell / Rightel) frequently filter or block non-standard outgoing HTTP ports (such as 8000, 8080, 8888) to foreign VPS IP addresses. Standard ports like 80 (HTTP) and 443 (HTTPS) are open.
Windows Defender Firewall / VPS Security Group:
Port 8000 must have an active Inbound rule in Windows Defender Firewall (New-NetFirewallRule -DisplayName "FastAPI 8000" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow).
The VPS provider (userver.ir) may have a hardware firewall/security group in their client portal blocking port 8000.
Frontend API URL Resolution in frontend/src/services/api.js:
baseURL must correctly resolve to the public IP/hostname of the server.
If using a single reverse proxy (e.g. Caddy, Nginx for Windows, or FastAPI static mounting), baseURL: '/api/v1' routes everything over standard Port 80, completely eliminating the Port 8000 filtering problem!
Performance on Remote Goal & Task Creation:
Optimistic UI, Promise.all parallelization on data fetch, and avoiding sequential round-trips from Iran to Germany.
Applying the compact 2-column mobile grid to GoalsPage.vue and RoadmapPage.vue.
